# Steam Workshop Page

## Title

Spider Fuel

## Description

Allows Silk and Spider Glands to be used as burnable fuel.

Features:
- Silk can be used as fuel.
- Spider Glands can be used as fuel.
- Fuel values are configurable for each item.
- Spider Glands default to Tiny fuel value.
- Silk defaults to Small fuel value.
- Server-side mod; clients do not need to install it separately.

Configuration:
- Spider Gland Fuel Value: Tiny, Small, Medium
- Silk Fuel Value: Tiny, Small, Medium
